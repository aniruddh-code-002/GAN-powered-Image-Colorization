# GAN-powered-Image-Colorization
A GAN model trained to predict the colors in black and white colored images
The Unsupervised learning was used in this model

Run train.py file to initiate the data training
Update Data file you can use your own or any other image dataset or you can use kaggle dataset link that i attached.
Just make sure to have images with diverse amount of colours for training. So that the model training can be optimized.

The model training was done for 150 epoches locally but due to the huge size of the model and limited internet i was not able to upload the model files 
and for data set files i have provided the kaggle link from where you can download the dataset

as for the models and outputs folder, they will be updated on the run. 
Make sure to clear models and outputs folder to avoid some potential errors.

This code utilizes the GPU especially using the CUDA library so make sure CUDA is installed.
